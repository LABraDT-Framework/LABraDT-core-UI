Project

                –
                
                  
                  
                  
                
              

              
The three component projects this UI configures and starts. What you configure is written into them: machine configs into the gateway project, rules (AASX) and service files into the engine project, the Gateway plugins and runtimes into each project's plugins/ folder (at every start and plugin install, or now with Apply to Projects). The projects then also run on their own with mvn spring-boot:run. Export Project saves everything, plugins included, as one .zip; Import Project restores such a file into the folders chosen here.

              

              
            

            

              

                
Components

                Idle
                
                  
                  
                  
                  
                
              

              
Starts the three component projects with Maven in dependency order: Runtime (Service Manager) → Gateway → Engine. The first start of a project builds it (mvn -DskipTests install); tick Build first to rebuild after code changes. The Gateway reads its machine configs directly from the gateway project folder, so config changes only need a Gateway restart.
